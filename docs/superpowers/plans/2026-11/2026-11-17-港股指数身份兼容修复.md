## P2 服务：归一化、版本策略、resolve

1. 归一化：
   - 在 `utils/symbols.py` 或目录模块内增加统一的指数文本归一：NFKC、大写、空白、标点、市场后缀、官方代码补零、A 股六位补零。
   - 不剥离 `.00`；不把五位港股个股代码当指数。
   - `normalize_index_symbol`/`validate_index_symbol` 保持向后兼容；A 股/港股个股路径不受影响。
2. 解析：
   - `IndexMapping.resolve` 改为归一化匹配：symbol / identity / name / aliases 精确优先；精确未命中进入基名精确层，再退到子串。
   - 基名精确：去掉尾部收益版本限定词（含单独“收益”）和尾部“指数”后比较；查询长度 <3 不用本层。基名命中后不再混入更低层子串结果。
   - 候选按 version family 分组：优先 `(provider, series_code)`，缺失回退 `(provider, market, base_name)`；多个 family 返回歧义。
   - family 内按 `return_type` 做价格/TRI/NTRI 选择；未指定版本且恰有一个价格条目时选价格；单独“收益”视为版本不明确；指定版本无匹配返回 not_found；同一版本多个条目返回歧义。
   - `恒生科技` 必须走“基名精确 + 同一 family（price/TRI/NTRI）+ 默认价格”，不能因为子串命中三个版本就报歧义。
   - 未来 short name 重复时返回歧义，不自动选。
   - `legacy_hk` 去重保留，避免 CSV 旧代码与官方价格条目被当成两个 family。
3. resolve 接口：
   - 在 `src/api/app.py` 增加 `GET /api/v1/indices/resolve`。
   - 返回 `status=ok/ambiguous/not_found`；空 q 422；内部异常 500/503。
   - 成功/歧义/未收录都返回 `catalog` 状态；字段名按设计 4.5。
   - 只读，不触发刷新。
4. 测试：
   - `tests/api/test_index_catalog.py`、`tests/api/test_index_catalog_expansion.py`：resolve 成功/歧义/未收录、市场返回、catalog 字段。
   - `tests/utils/test_index_symbols.py`：归一化矩阵、代码补零、`.HK/.SH/.SZ`、全角/空格/标点。
   - `tests/data/test_index_catalog_sources.py`：价格/TRI/NTRI 不混；`series_code` family 分组。
   - 基名/版本用例：`恒生科技` → 价格；`恒生科技总收益` → 毛收益；`恒生科技净收益` → 净收益；`恒生科技收益` → 歧义；`恒生科技美股` → 歧义；`恒生科技美股半导体` → 价格。

## P5 插件：刷新控制、队列归并、补发

1. 刷新控制：
   - 由 resolve 的 `catalog` 状态驱动：`hsi_loaded=false` / `hsi_aliases_loaded=false` / `hsi_updated_at` 超过 7 天时刷新一次。
   - 已加载、别名已加载、未过期：不刷新；歧义/美股/未知市场/网络错误：不刷新。
   - 进程内单飞锁；成功冷却 10 分钟、失败 60 秒；刷新超时 12 秒；剩余预算不足 20 秒不刷新。
   - 刷新 404/405、stale、超时分别映射文案；刷新失败保留旧目录。
2. 队列：
   - 入队保存归一化 query；有 resolve 缓存时保存官方 symbol。
   - 去重优先官方 symbol，其次归一化 query。
   - 服务恢复后先 resolve 每个目标，多个目标指向同一官方 symbol 时合并，只分析一次。
   - 缓存来自服务返回的 aliases/symbol，存插件数据目录；不写死别名。
3. 补发：
   - 解析成功后固定官方 symbol；超时补发使用该身份，不重新 resolve。
   - 恢复/批量路径同样使用队列中已解析的官方身份。
4. 测试：
   - `tests/test_client.py`：刷新触发矩阵、冷却、单飞、超时、404、stale。
   - `tests/test_pending_queue.py`：`HSTECH`/`HSTECH.HK`/`恒生科技` 入队合并（有缓存/无缓存）、A 股回归。
   - `tests/test_plugin_storage.py`/`test_waiting_messages.py`：队列批量合并、补发身份。
   - 并发 `asyncio.gather` 只触发一次 POST。

验收：首次无目录/旧快照无别名自动刷新一次；已有目录不刷新；并发只刷新一次；队列不因别名占多个槽；补发不重复解析。
