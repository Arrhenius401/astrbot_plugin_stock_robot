# 插件默认安装最新正式版

用户已确认首次安装默认获取stock_robot最新正式发布版，已有安装普通重载不升级，stock_robot保持插件所用API向后兼容。

未配置source_archive_url且本地没有有效源码时，使用GitHub公开API查询Arrhenius401/stock_robot的最新正式Release。校验标签和draft/prerelease状态后，按固定标签下载源码ZIP。记录release_tag、release_id、实际归档地址与SHA256；SHA256是下载内容记录，不冒充发布方签名或预期摘要校验。查询和下载共用原有下载总超时，不叠加SDK重试。

已有源码、安装记录和自定义归档地址保持兼容。有效本地源码优先复用，不访问Release接口；配置为空表示最新正式版，自定义固定归档仍可使用。锁定依赖、配置保留、进程所有权和报告发送行为不变。

无正式Release（404）、网络异常、无效响应或源码缺锁清单时明确失败，不回退开发分支。只有检查归档结构和所需锁清单后才能发布到instance/src，避免无效归档占住安装目录。核心锁清单始终必需；启用rag时另需rag锁清单。

2026-10-08 用户确认限流处理补充：仅当 API 明确限流时，查询 GitHub 官方 latest 网页的一次重定向，严格校验同仓库 HTTPS 标签地址，再用 codeload 下载固定标签源码。正常 API 查询也使用 codeload 归档地址；备用查询失败明确报错，不重试限流 API。来源记录增加 release_resolution，网页渠道不伪造 release_id；旧记录、离线复用和自定义归档保持兼容。具体响应识别、边界和分阶段验证见对应限流处理实施计划。
