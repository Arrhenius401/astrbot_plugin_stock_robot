<h1 align="center">股票分析助手</h1>

<p align="center"><strong>在 AstrBot 聊天中分析 A 股/港股个股、A 股指数与黄金市场观察，直接收取研报图片</strong></p>

本插件内置分析服务。你可以询问一只 A 股、港股、一个 A 股指数，或生成黄金市场观察简报；机器人会发送准备与分析进度，并把完整研报以图片发到当前聊天。插件自动安装当前绑定的服务版本，具体版本见[更新日志](CHANGELOG.md)。

## 快速开始

需要 **AstrBot 4.27.0 及以上**，运行 AstrBot 的 Python 版本须为 **3.11 及以上**。聊天模型需要支持工具调用，并允许使用本插件提供的工具。

### 1. 安装并启用插件

在 AstrBot **插件市场**中搜索“股票分析助手”，安装并启用。

也支持在插件管理中通过[仓库地址](https://github.com/Arrhenius401/astrbot_plugin_stock_robot)安装，适用于上架前体验或手动安装。

保留默认配置，插件会自动在 AstrBot 所在环境中安装并启动分析服务。首次安装需要能访问 GitHub 和 Python 依赖下载源。

### 2. 等待首次准备完成

首次准备包括下载插件绑定的内置分析服务、安装依赖和启动服务，可能需要几分钟。你可以在插件数据目录的 `service.log` 中查看进度；后续启用会直接复用已有安装。

### 3. 发送第一条分析请求

在已启用模型对话的聊天中发送：

> 帮我分析一下平安银行。

机器人会发送分析进度，随后将完整研报以图片发到聊天中。首次配置会尝试沿用 AstrBot 默认的 OpenAI 或 Anthropic 模型；你也可以在运行 AstrBot 的主机上打开 <http://127.0.0.1:25618>，设置用于生成研报的模型。

Docker 部署需持久化插件数据目录；`127.0.0.1` 指 AstrBot 容器自身，详细说明见[维护与排障](docs/维护与排障.md)。

## 它能做什么

- **A 股/港股个股研报**：默认提供行情、财报、新闻、来源与可复核指标；开启额外分析后增加五维综合评分、申万或 HSICS 行业同期对比、规则信号与 AI 综合解读。
- **A 股指数研报**：宽基、行业、策略等 A 股指数；港股/美股指数暂不在插件入口内。默认提供客观数据，开启额外分析后增加研判与 AI 解读。
- **黄金市场观察简报**：国内 Au99.99 与国际 XAU 价格、实际利率、美元/汇率、官方储备与 SPDR 持仓等市场观察；逐项标注来源与数据日期，不提供买卖建议。
- **进度与图片交付**：分析过程有进度提示，完整研报以图片发送；图片失败时发送 Markdown 或 ZIP。
- **可选额外分析**：开启后港股报告启用五维评分和 HSICS 行业对比，并按综合分生成规则信号；不提供港股仓位建议。A 股信号仍按原财务/技术/估值三核心门槛判断。黄金、配置雷达和回测不受该开关影响。

## 怎么使用

直接告诉机器人你想了解哪只股票、哪个 A 股指数，或想要黄金市场观察：

| 想做什么 | 消息示例 |
| --- | --- |
| 按股票名称 | 帮我分析一下贵州茅台。 |
| 按股票代码 | 分析一下 600519。 |
| 按指数名称 | 沪深 300 最近表现怎么样？帮我生成一份研报。 |
| 按指数代码 | 帮我分析指数 399006。 |
| 黄金市场观察 | 今天黄金市场怎么看？生成一份黄金市场观察简报。 |

港股可输入 `00700`、`00700.HK` 或 `hk00700`。对于同名标的或股票、指数共用的代码，可以在请求中补充具体名称或类型，帮助模型识别。

研报由内置分析服务生成，并通过 AstrBot 的文字转图能力发送到当前聊天。

## 按需配置

在 AstrBot 的插件配置页修改以下选项，保存后重载插件。

| 配置项 | 默认值 | 什么时候需要改 |
| --- | --- | --- |
| 额外分析 | 关闭 | 为个股和指数增加规则判断及 AI 解读；个股另提供评分与模型信号。默认关闭。 |
| 清理历史原始报告 | 开启 | 删除 7 天前的个股、指数和黄金报告；不可恢复。 |
| 分析服务端口（`service_port`） | `25618` | 通常不必修改，端口冲突时更换；范围 1～65535。 |
| 单次分析最长等待时间（秒） | `150` | 单次分析等待上限；AstrBot 工具超时建议至少 180 秒。股票/指数超时后会后台补发。 |
| 服务就绪最长等待时间（秒） | `60` | 服务未就绪时本次请求的等待上限；超时后后台继续准备。 |
| 后台安装最长用时（秒） | `1800`（30 分钟） | 下载、安装依赖和换源的总时限；慢网络可调大。 |
| Python 安装包下载源（选填） | 留空 | 留空先用清华源，失败后沿用安装工具原有设置；也可填写自定义 pip 源。 |

如果使用 AstrBot 4.29 及以上，请将 `agent_runner.config.misc.tool_call_timeout` 设为至少 180 秒；旧版对应 `provider_settings.tool_call_timeout`。实际等待取插件配置与工具时限扣除 15 秒后的较小值，流程另预留 5 秒收尾。

`extra_analysis_enabled` 默认关闭，已有配置缺项也按关闭处理。该项作用于整个内置分析服务：修改后重载插件，插件在启动自建服务前写入服务配置，并与服务 Web 配置页的“启用额外分析”保持同步；Web、CLI、订阅以及共用该服务的其他客户端的新报告会一并遵循。复用外部启动的服务时不写入其配置；开关与实际服务不一致，或服务版本不支持该设置时，会在首次分析前给出提示。客观模式仍保留行情、财报、新闻、来源、日期和缺失说明，历史报告不会随开关变化重写；黄金、配置雷达和回测不受影响。AI 解读仍受模型配置和 `llm.enabled` 约束，本开关不会修改模型设置。

`cleanup_previous_reports` 默认开启，实际清理由内置分析服务执行：删除超过 7 天的个股、指数和黄金报告单元（Markdown 与结构快照），无法识别的文件保留；保留期固定为 7 天。插件在启动自建服务前把该项写入服务配置，并与服务 Web 配置页的“自动清理过期报告”保持同步；复用外部服务时不读取、不修改其配置。清理间隔可在该服务配置页的完整配置文件编辑器中修改。包源地址示例：`https://pypi.tuna.tsinghua.edu.cn/simple`；示例仅用于说明，不会自动填入配置，安装过程不修改系统全局包源。

### 设置研报模型

首次配置会尝试复制 AstrBot 默认 OpenAI 或 Anthropic 模型的 API Key、模型名和接口地址。此后，研报模型在内置分析服务的 Web 配置页中单独管理；切换 AstrBot 的聊天模型时，研报模型保持原有设置。Azure 模型、代理和自定义请求头等扩展设置需在服务侧配置并确认兼容性。

## 常见问题

### 首次使用提示服务未就绪

首次安装可能需要较长时间，后台准备会继续进行，稍后重新发送请求即可。持续未就绪时，可在 `service.log` 中查看下载、依赖安装和启动情况；阶段日志、超时和包源细节见[维护与排障](docs/维护与排障.md)。

### 机器人没有调用插件

分析通过 AstrBot 的模型工具调用触发。请检查当前聊天的模型是否支持工具调用，以及 `analyze_stock`、`analyze_index`、`analyze_gold` 是否已启用。对于同名标的或股票、指数共用的代码，可以在请求中补充具体名称或类型。

### 报告显示“AI 解读当前不可用”

先确认已开启“额外分析”。关闭时报告为客观数据模式，不请求 AI，也不会显示该提示；开启后可在分析服务的 Web 配置页检查模型、API Key 和接口地址。详细原因记录在 `instance/.stock_robot/runtime-*.log` 中。如果日志提示输出长度不足，可在服务配置页清空“最大 Token 数”并保存，使用自动输出预算。

### 提示“额外分析开关未生效”

当前分析服务版本过旧，或该服务由外部/其他插件实例管理。请先把内置服务升级到插件绑定的正式版本，或在服务的 Web 配置页设置“启用额外分析”；插件不会修改外部服务的配置。

### 分析经常超时

检查插件的 `timeout_seconds` 与 AstrBot 的 `provider_settings.tool_call_timeout`，实际使用两者中较小的值。准备服务、分析和取报告共用这一次调用的时间；取到原文后图片与文件在后台交付。

### 图片发送失败或中文缺字

图片失败时会发送完整 Markdown 文件，平台明确拒绝文件大小时再尝试 ZIP。中文缺字、字体安装、转图回退和交付限制见[维护与排障](docs/维护与排障.md)。

## 使用边界

个股分析支持 A 股与港股（港股可输入 `00700`、`00700.HK` 或 `hk00700`）。默认只提供客观数据；开启额外分析后，港股使用恒生 HSICS 行业对比与五维综合评分，并按综合分生成规则信号，但不提供仓位建议；A 股信号继续以财务、技术、估值三核心门槛为准，阈值和仓位不变。

指数分析仅支持 A 股指数，数据覆盖范围取决于内置分析服务。默认只提供客观数据；开启额外分析后才增加规则判断与 AI 解读，不新增指数评分、模型信号或仓位。黄金市场观察简报为价格优先的市场观察，逐项披露数据日期与缺失状态，不提供买卖建议。公开数据可能延迟或缺失，报告会受到数据源与模型可用性的影响。本工具用于学习与研究，报告不构成投资建议。

## 关于内置分析服务

分析能力由内置分析服务提供（开源项目 Stock Robot，Apache-2.0，[源码](https://github.com/Arrhenius401/stock_robot)）。该服务由插件作者维护，在 AstrBot 所在环境自动安装和运行，不依赖外部托管服务，不上传聊天内容；行情来自公开数据源；开启额外分析且配置模型时，研报解读由该模型生成。
